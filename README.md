DAA-Lab

Design and Analysis of Algorithms (DAA) Lab - RGUKT-Ongole

This repository contains my **Design and Analysis of Algorithms (DAA) Lab** programs, algorithms, sample inputs, outputs, and related lab work completed as part of my engineering coursework.

## 📚 About the Repository

The purpose of this repository is to maintain and organize the programs implemented during the DAA laboratory sessions.

The programs cover important algorithmic techniques such as:

* Divide and Conquer
* Greedy Method
* Dynamic Programming
* Backtracking
* Graph Algorithms
* Minimum Spanning Tree
* Shortest Path Algorithms
* Sorting and Searching

## 🧩 Algorithms & Programs

Some of the algorithms covered in this repository include:

* Binary Search
* Merge Sort
* Quick Sort
* Knapsack Problem
* Prim's Algorithm
* Kruskal's Algorithm
* Dijkstra's Algorithm
* Floyd-Warshall Algorithm
* Travelling Salesman Problem (TSP)
* N-Queens Problem
* And other DAA laboratory experiments
